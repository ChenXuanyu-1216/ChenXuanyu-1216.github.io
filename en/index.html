Smaller builds

SourceTrace

Agent Skill, Python

AI tools can turn lecture slides into a knowledge tree in seconds, but a definition may be wrong, a relationship made up, or a key point missing. SourceTrace is an Agent Skill that checks every node and link in the tree against the original slide images, and backs each finding with the page and a quote. I have tested it in Claude Code and Codex on several Chinese lecture decks and Wikipedia screenshots.

GitHub source

DailyBoss

Browser game, React / TypeScript / Three.js

A small game that turns everyday frustrations into boss fights: you only want to print one page, and the printer becomes today’s final boss. The first level, Printer From Hell, can be played from start to finish. It is not online yet and has not been playtested.

Source code is private

SameWords

AI agent, Python / PydanticAI

The same phrase, like “whatever you want”, can mean different things in different situations. SameWords helps researchers design experiments on how people read such phrases: you describe an idea, it drafts an experiment plan, checks it with fixed rules, and revises it at most once. It only writes drafts and never recruits participants or collects data. The first phase, a command-line version, is done.
